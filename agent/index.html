Synapse turned each one's existing API into an MCP server, without changing their code. This agent uses both, bridging village names and official village codes. How it works

  1. synapse build --local --auto read each FastAPI codebase and generated synapse_auto_server.py.
  2. Only village-level recap endpoints are exposed. Record-level routes stay inside each agency (data minimisation, UU PDP).
  3. For every question the agent opens both MCP servers, lists their tools and plans the calls.
  4. New endpoint? synapse build --discover rebuilds the server and the next question can use it.
